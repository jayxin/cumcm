\section{其它}

\subsection{脚注}

用 \verb|\footnote{具体内容}| 可生成脚注\footnote{脚注可以补充说明一些东西}。

\subsection{无序列表与有序列表}

无序列表：
\begin{itemize}
  \item xelatex
  \item pdflatex
  \item lualatex
  \item etc.
\end{itemize}

有序列表：
\begin{enumerate}
  \item xelatex
  \item pdflatex
  \item lualatex
  \item etc.
\end{enumerate}

\subsection{字体加粗与斜体}

若想强调部分内容，可用加粗来实现。加粗字体可用 \verb|\textbf{加粗}| 来实现。如： \textbf{这是加粗的字体。 This is bold fonts} 。

中文字体没有斜体设计，但英文字体有。\textit{斜体 Italics}。
